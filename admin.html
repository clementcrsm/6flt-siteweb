Connexion GitHub

Le token reste uniquement dans ce navigateur (localStorage), il n'est envoyé qu'à l'API GitHub. Pour le créer : GitHub → Settings → Developer settings → Fine-grained tokens → accès limité à ce dépôt, permission « Contents : Read and write ». Chaque sauvegarde publie automatiquement le site (1 à 2 minutes de délai).
